# ADR 0004: Julia 1.12 minimum

Date: 2026-09-06. Status: accepted.

## Context

The rest of the ecorecipes org is harmonised on `julia = "1.11"` with CI matrix `['1.11', '1']`. The user asked for
this ecosystem to target Julia 1.12+.

## Decision

Every package sets `julia = "1.12"` in `[compat]` and tests on `['1.12', '1']` (Ubuntu), plus latest on macOS and
Windows. Catlab 0.17.6, ACSets 0.2.29 and GATlab 0.2.4 precompile on Julia 1.12.7 locally.

## Consequences

This deviates from the org floor. Nothing in the design requires 1.12-only features (`[sources]` needs 1.11), so the
floor can be lowered later by editing `[compat]` and the CI matrix if org-wide consistency is preferred.
